# 🎓 EduFlow — образовательная платформа

Полнофункциональный образовательный сайт на **React + Tailwind CSS**. Вся логика (регистрация, вход, корзина, прогресс обучения) реализована на фронтенде с сохранением в `localStorage`.

## Возможности

- 🏠 **Главная** — hero-блок, статистика, направления, популярные курсы, преимущества, CTA
- 📚 **Каталог** — фильтрация по категориям (программирование / дизайн / языки) и уровню сложности, сортировка, поиск
- 🎴 **Карточка курса** — название, описание, уровень, цена (со скидкой), рейтинг, длительность
- 🔐 **Регистрация / Вход** — валидация форм, «база» пользователей в localStorage
- 👤 **Профиль** — прогресс обучения с прогресс-барами и статистикой (защищённый маршрут)
- 🛒 **Корзина** — добавление/удаление, подсчёт суммы и скидки, оформление заказа
- 📱 **Адаптивный дизайн** — мобильное меню-бургер, адаптивные сетки
- 🔎 **Навигация с поиском** в шапке

## Стек

- React 18 + Vite
- React Router 6
- Tailwind CSS 3
- Состояние: `useState` + `useContext` (AuthContext, CartContext)

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  components/   Navbar, Footer, CourseCard, Badge, ProtectedRoute
  context/      AuthContext, CartContext
  data/         courses.js (7 курсов + категории + уровни)
  pages/        Home, Catalog, Login, Register, Profile, Cart
  App.jsx       маршруты
  main.jsx      точка входа + провайдеры
```

## Демо-данные

В каталоге **7 курсов** по трём направлениям. После регистрации в профиле сразу появляются два курса с прогрессом (для демонстрации прогресс-баров) — прогресс можно менять кнопками «Пройти урок» / «Завершить курс».
